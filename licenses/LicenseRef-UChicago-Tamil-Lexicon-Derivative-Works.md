# Tamil Lexicon Headword Authorization

Written authorization was received by Anand Murugan from University of
Chicago department representatives on 2026-07-23 to use the supplied
University of Madras Tamil Lexicon headwords in derivative works.

For this project, the recorded authorization applies to derived lexical
classifications, modified FST lexicons and patches, compiled FST models,
tokenizer vocabularies, and generated dictionaries.

The authorization did not expressly address standalone, verbatim
redistribution of the original supplied headword snapshot. That source file is
therefore retained as a private build input and excluded from public release
archives.

The original email is retained privately by the project owner. This file
records the authorization date and operative scope without reproducing private
correspondence.
