The standalone adjective model is not the ceiling on modifier coverage.
Lexical and adjective-derived behavior remains in `adj.fst`; every noun-led
copular `-ஆன`, privative `-அற்ற`, relational, existential, compound, or
nominalized modifier relation is owned by `noun.fst`. The source class
therefore retains responsibility for stem alternations such as
`தடை → தடையற்ற` and `அளவு → அளவற்ற`, with no duplicate noun analysis in the
adjective model.

The adverb model similarly preserves typed source structure for reviewed
translative and distributive expressions. It does not bulk-classify role
predicates, purpose forms, or verbal/complement `-தாக` forms as adverbs.
